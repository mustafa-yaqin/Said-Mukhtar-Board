# YAQIN-CODE | Kanban Board

A drag-and-drop Kanban board built with React and Vite.

## Features
- Drag cards between lists, or drop on a card to place it before it
- Add and delete cards
- Board is saved in localStorage
- Reset to the default board

## Run
```bash
npm install
npm run dev
```

## Build / Deploy (GitHub Pages)
```bash
npm run deploy
```
